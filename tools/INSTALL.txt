Sailwind Co-op v0.4.0  [game v0.38.1]

This version needs the Sailwind Player Model mod. It is included in this zip and installs
alongside co-op. If you already have Sailwind Player Model installed, this zip overwrites it
with the version co-op was built against. Older Player Model versions turn themselves off when
they see an older co-op, so keep the two in step.

Settings that moved:
 - The [Crouch] entries in co-op's config now live in the Player Model config
   (BepInEx\config\com.diamondminer99.playermodel.cfg, section "1. Pose").
 - [Coop] MenuButtonScale moved to the same file, section "4. Menu".
 Defaults are unchanged. If you had tuned them, enter your values there once.

1. Quit Sailwind.
2. Unzip this WHOLE archive into your Sailwind install folder, the one containing Sailwind.exe
   (for example ...\steamapps\common\Sailwind). Overwrite when asked. Extract the full zip, not
   just the DLLs; it ships:
     - BepInEx\plugins\SailwindCoop\SailwindCoop.dll
     - BepInEx\plugins\SailwindCoop\Facepunch.Steamworks.Win64.dll  (the Steam wrapper)
     - BepInEx\plugins\SailwindPlayerModel\SailwindPlayerModel.dll  (the player model mod)
     - steam_api64.dll  (the native Steam library, next to Sailwind.exe)
3. Launch Sailwind. Press F8 once in-game to enable background co-op logging.
4. The host invites you from the pause menu (Esc, Invite Friend). Accept the Steam invite.

Back up your saves first. This is alpha software; crashes and desyncs are possible.

If the game crashes or co-op misbehaves, send these BEFORE relaunching (the verbose log is
overwritten each session):
  - <Sailwind>\BepInEx\LogOutput.log
  - <Sailwind>\BepInEx\SailwindCoop-verbose.log  (only if you pressed F8)
  - %USERPROFILE%\AppData\LocalLow\Raw Lion Workshop\Sailwind\Player-prev.log
